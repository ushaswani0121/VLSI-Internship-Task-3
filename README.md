# Verilog RTL Design of Sequential Circuits and Flip-Flops

This repository contains the Verilog HDL implementation and simulation of fundamental sequential circuits used in digital electronics and VLSI design.

## Modules Implemented
- D Flip-Flop
- JK Flip-Flop
- 4-bit Register
- 4-bit Binary Counter

## Tools Used
- Verilog HDL
- Xilinx ISE

## Features
- Edge-triggered sequential circuit implementation
- Asynchronous reset functionality
- Enable-controlled data loading and counting
- Dedicated testbenches for functional verification
- Waveform analysis and validation

## Project Structure
```

.

├── jk_flip_flop_tb.v

├── reg_4bit_tb.v
├── counter_4bit.v

```

## Simulation Results
All modules were simulated using Xilinx ISE. The generated waveforms verified:
- Correct clock-driven behavior
- Proper state transitions
- Reset signal priority
- Accurate storage and counting operations

## Applications
- VLSI Design
- RTL Design
- FPGA Development
- ASIC Design
- Digital System Design

## Conclusion
This project demonstrates the successful implementation and verification of essential sequential circuits using Verilog HDL, providing a strong foundation in RTL design and digital systems.
